      Save for everyone

      Saving writes your changes to event-edits.json in the GitHub repo, so everyone who opens this page sees them and the hourly CSV includes them. GitHub needs a token to let this page write. You only do this once per browser.

      1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
      2. Repository access: only . Permissions: Contents → Read and write.
      3. Paste the token here. It stays in this browser and is only sent to GitHub.
